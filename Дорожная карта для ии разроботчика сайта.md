# 7. СОЕДИНЕНИЯ

Основная сила приложения — связи между объектами.

### Smart Routing

Система сама определяет оптимальный путь.

Connections должны автоматически адаптироваться при перемещении объектов.

Продумай:

- arrowheads;
- edge labels;
- edge categories;
- edge colors;
- relationship types;
- relationship metadata;
- directional/non-directional links;
- edge selection;
- edge editing.
